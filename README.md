# Octopath Traveler II — Archipelago PopTracker

PopTracker pack for the **Octopath Traveler II Archipelago randomizer**.

This pack is designed to be used with [PopTracker](https://github.com/black-sliver/PopTracker/releases/tag/v0.35.4) and provides an interactive tracker for progression items, characters, regions, chapters and map checks.
---

## ✨ Features

### Characters

Tracks all 8 playable characters:

- Ochette
- Throne
- Temenos
- Osvald
- Castti
- Hikari
- Partitio
- Agnea

Starting characters are automatically activated.

### Regions

Tracks the 8 main regions:

- Toto'haha
- Brightlands
- Crestlands
- Winterlands
- Harborlands
- Hinoeuma
- Wildlands
- Leaflands

The starting region is automatically activated, and newly received region unlocks are tracked automatically.

The **Sundering Sea** is also represented on the world map.

### Other progression items

- The Boat
- The Grand Terry
- Time Change
- Secondary Job Licenses

### Story chapters

A dedicated **Chapters** tab tracks the available character and crossed-story chapter progression items.

The tracker follows the progression items provided by the Archipelago.
### Maps

The tracker includes:

- A world map showing region progression
- Detailed regional maps
- Map locations for Archipelago checks
- Automatic map check state updates

Checks change state as they become available or are collected.
---

## 📦 Installation

### Requirements

- [PopTracker](https://github.com/black-sliver/PopTracker/releases/tag/v0.35.4)

### Installing the pack

1. Download the latest release from the **Releases** section.
2. Put the pack into your PopTracker `packs` directory.
3. Start PopTracker.
4. Select the **Octopath Traveler II — Archipelago** pack.
5. Connect PopTracker to your Archipelago session.

The pack uses Archipelago autotracking, so progression items and checked locations are updated automatically when connected to a compatible Archipelago game.
